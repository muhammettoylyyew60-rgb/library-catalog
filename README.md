# Библиотечный каталог

## Описание

Учебное приложение «Библиотечный каталог», разработанное на Python.

Приложение позволяет:

- добавлять книги;
- просматривать список книг;
- искать книгу по названию.

## Технологии

- Python 3.12
- Git
- GitHub
- GitHub Actions
- unittest

## Тестирование

Проект содержит два автоматических теста:

1. Проверка добавления книги.
2. Проверка поиска книги.

## CI/CD

GitHub Actions автоматически запускает тесты после каждого изменения кода и выполнения push в репозиторий.
